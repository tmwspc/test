いぶきGW ARカメラ

ファイル構成：
- index.html : 日本語版
- index_kids.html : キッズ向け日本語版
- index_en.html : 英語版
- kids/index.html : キッズ向け版（フォルダ版）
- en/index.html : 英語版（フォルダ版）
- ggw.glb : 3Dモデル

使い方：HTTPS対応のWebサーバーにファイルを置いて開いてください。カメラ利用にはブラウザのカメラ許可が必要です。
HTMLファイルと ggw.glb は同じフォルダに置いてください。kids/en フォルダ版を使う場合は、各フォルダにも ggw.glb を置いてあります。

主な操作：指1本で衛星を移動、2本指で拡大・縮小。ボタンで回転・傾き調整、アンテナアニメーションの一時停止、撮影・保存ができます。
