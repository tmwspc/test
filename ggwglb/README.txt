GOSAT-GW ARカメラ（GLB版）

内容
- index.html：カメラ＋3Dモデル表示＋写真保存ページ
- ggw.glb：以前提供されたGOSAT-GWの3Dモデル

使い方
1. ZIPを展開し、index.html と ggw.glb を同じフォルダに置いた状態にします。
2. このフォルダの内容を、HTTPS対応のWebサーバーにアップロードします。
3. スマートフォンで index.html を開き、「カメラ開始」を押してカメラを許可します。
4. 衛星を指1本で移動、2本指で拡大・縮小し、「撮影・保存」を押します。
5. PNG画像のダウンロードを許可し、端末のダウンロード先を確認します。

注意
- GLBモデルを読み込むため、index.html と ggw.glb は必ず同じフォルダに置いてください。
- カメラ利用にはHTTPSが必要なブラウザがほとんどです。file:// で直接開く方法では動かない場合があります。
- この版はカメラ映像に3Dモデルを手動で重ねる方式です。ARCore等の空間追跡・自動固定には対応していません。
- USDZはこのWebGL表示では使用しません。必要であれば、iPhone/iPad向けのAR Quick Look導線は別途追加できます。
- 写真保存はブラウザのダウンロード機能を使います。端末やブラウザによって保存確認の表示が異なります。


【修正版】
初版でThree.jsの読み込み設定が不足しており、GLTFLoaderが動かない環境がありました。修正版ではimport mapを追加しています。
モデル読込にはインターネット接続とHTTPS対応のWebサーバーが必要です。index.htmlをファイルアプリから直接開く方法では動作しない場合があります。


【表示修正版】
・GLBモデルの縮小と中央配置の計算を修正しました。
・スマートフォンでモデルが描画されない場合に備え、メッシュの表示設定も調整しています。
・index.html と ggw.glb は必ず同じフォルダに置いてください。
・まずHTTPSでページを開き、「モデルを読み込みました」と表示されてから「カメラ開始」を押してください。
・モデルが見えないときは「中央へ」を押してください。


【GLB診断版】
この版は、衛星モデルとは別に、WebGL描画を確認するための色付き立方体を画面中央に表示します。
1. スマホでHTTPS経由で開き、カメラ開始を押します。
2. 画面中央に回転する立方体が見えるか確認してください。
3. 「立方体 ON/OFF」で立方体を消すと、衛星モデルが見えるか確認できます。
判定：
・立方体が見え、衛星が見えない：GLBモデルの配置・材質・読み込み後処理を調査します。
・立方体も見えない：スマホでのWebGLキャンバス表示、重なり順、ブラウザ互換性を調査します。
・立方体が見えるがカメラ開始後に消える：カメラ映像と3Dキャンバスの重なり順を調査します。
