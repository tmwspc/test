GOSAT-GW ARカメラ — アンテナアニメーション・高解像度版

内容:
- index.html
- ggw.glb

使い方:
1. ZIPを展開し、index.html と ggw.glb を同じフォルダに置きます。
2. HTTPS対応のWebサーバー等から index.html を開き、カメラを許可します。
3. AMSR3アンテナは初期状態でアニメーション再生します。「アンテナ一時停止／アンテナ再生」で切り替えます。
4. 指で位置・大きさを調整し、ボタンで向きを調整できます。
5. 「撮影・保存」でカメラ映像と3Dモデルを合成したPNGを保存します。

改修:
- GLB内の GOSAT-GW_AMSR_antennaAction を再生。アニメーション対象は GOSAT-GW_AMSR_antenna ノードです。衛星全体はアニメーションしません。
- 初期向きを斜め前に調整。
- カメラ映像の実ピクセル寸法（videoWidth × videoHeight）で合成画像を作成。
- カメラは可能な範囲で 1920×1080 を要求します。実際の保存解像度は端末・ブラウザ・カメラが選んだ解像度に依存し、撮影後に画面へ表示します。

注意:
カメラ利用にはHTTPSまたはlocalhost等の安全なコンテキストが必要です。ブラウザのカメラ許可が必要です。
