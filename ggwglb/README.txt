GOSAT-GW ARカメラ（GLB版）

内容
- index.html：カメラ＋3Dモデル表示＋写真保存ページ
- ggw.glb：以前提供されたGOSAT-GWの3Dモデル

使い方
1. ZIPを展開し、index.html と ggw.glb を同じフォルダに置いた状態にします。
2. このフォルダの内容を、HTTPS対応のWebサーバーにアップロードします。
3. スマートフォンで index.html を開き、「カメラ開始」を押してカメラを許可します。
4. 衛星を指1本で移動、2本指で拡大・縮小し、「撮影・保存」を押します。
5. PNG画像のダウンロードを許可し、端末のダウンロード先を確認します。

注意
- GLBモデルを読み込むため、index.html と ggw.glb は必ず同じフォルダに置いてください。
- カメラ利用にはHTTPSが必要なブラウザがほとんどです。file:// で直接開く方法では動かない場合があります。
- この版はカメラ映像に3Dモデルを手動で重ねる方式です。ARCore等の空間追跡・自動固定には対応していません。
- USDZはこのWebGL表示では使用しません。必要であれば、iPhone/iPad向けのAR Quick Look導線は別途追加できます。
- 写真保存はブラウザのダウンロード機能を使います。端末やブラウザによって保存確認の表示が異なります。
